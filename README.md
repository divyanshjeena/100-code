# 100 Days of Code: C

Completed all 100 days of the official C question curriculum.

| Days | Questions | Solutions per day | Status |
| --- | --- | --- | --- |
| 1–50 | Q1–Q100 | 2 | Complete |
| 51–100 | Q101–Q150 | 1 | Complete |

Each day folder contains standalone C programs. Each source file starts with the
full question statement. The official category `Loops without Arrays/Strings`
uses `Loops without Arrays-Strings` in filenames because `/` is not valid in a
Windows filename.

Compile a solution with:

```sh
gcc -std=c11 -Wall -Wextra -pedantic "Day 1/Q1 (User Inputs, Operations & Output).c" -lm
```
